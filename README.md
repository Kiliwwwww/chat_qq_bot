# QQ Chat Bot

基于 [NoneBot2](https://nonebot.dev/) 的多功能 QQ 机器人，支持 AI 对话、群聊管理、知识库检索、微博动态、今日老婆以及修仙挂机游戏等功能。

## 插件概览

| 插件 | 说明 |
|------|------|
| `chat_ai` | AI 对话、白名单管理、人格切换、广告撤回、知识库、主动冒泡 |
| `ranking` | 基于 Redis 的每日群消息排行榜 |
| `weibo` | 查看微博用户最新动态与图片 |
| `daily_wife` | 今日老婆 / 原神家庭（头像合成图片） |
| `xiuxian` | QQ 群修仙挂机游戏 |

## 功能特性

- **AI 对话**：接入 OpenAI 兼容 API，支持上下文记忆与多 AI 服务切换
- **图片识别**：支持发送图片给 AI 分析（视觉 API）
- **知识库检索**：接入 RAGFlow，AI 自主决定是否检索群知识库
- **聊天记录总结**：定时/手动将群聊记录与总结同步至知识库
- **群聊概率回复**：可配置回复概率与冷却，避免刷屏
- **主动冒泡**：群聊冷清时主动发言暖场（AI 生成 + 预设语兜底）
- **私聊/群聊白名单**：仅允许指定用户私聊、仅在指定群启用
- **人格切换**：默认「雌小鬼」与「邻家大姐姐」两种人格
- **广告检测与撤回**：关键词 + AI 双重判定，自动撤回广告消息
- **复读检测**：自动跟随群友复读消息，支持随机复读
- **表情贴纸**：给指定用户/全体群友消息自动贴表情
- **欢迎语系统**：新成员入群自动发送欢迎语
- **管理员系统**：通过命令管理白名单、提示词、AI 服务等
- **排行榜**：基于 Redis 的每日群消息排行榜
- **微博动态**：查看微博用户最新动态和图片
- **今日老婆 / 原神家庭**：每日抽取 CP 并合成头像图片
- **修仙游戏**：完整的挂机修仙玩法（灵修 + 蛊修）

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境

复制并编辑 `.env` 文件：

```bash
cp .env.example .env
```

主要配置项：

```env
# AI 配置
ai_api_key=你的API密钥
ai_base_url=https://api.example.com/v1
ai_model=mimo-v2.5

# 管理员QQ号（只有此人可修改白名单等设置）
admin_qq=123456789

# 群消息回复概率 (0.0~1.0)
group_reply_chance=0.05
```

### 3. 运行机器人

```bash
python bot.py
```

### 4. 访问文档

启动后访问 http://localhost:8080/website/ 查看 API 文档。

OneBot 反向 WebSocket 连接地址：`ws://localhost:8080/onebot/v11/ws`。

> 使用 Docker 部署请参考 [DEPLOY.md](./DEPLOY.md)。

## 配置说明

在 `.env` 文件中配置以下参数：

### AI 配置（chat_ai）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `ai_api_key` | - | OpenAI API 密钥 |
| `ai_base_url` | `https://api.xiaomimimo.com/v1` | API 地址 |
| `ai_model` | `mimo-v2.5` | 模型名称 |
| `ai_max_tokens` | `1024` | 最大生成长度 |
| `ai_temperature` | `1.0` | 生成温度 |
| `ai_top_p` | `0.95` | Top P 采样 |
| `ai_context_limit` | `50` | 上下文历史记录条数 |
| `admin_qq` | `1154798056` | 管理员 QQ 号 |
| `admin_name` | `宝宝葵` | 管理员昵称（用于提示词替换） |
| `group_reply_chance` | `0.05` | 群聊回复概率 (0.0~1.0) |
| `random_repeat_chance` | `0.03` | 随机复读概率 (0.0~1.0) |
| `group_emoji_chance` | `0.3` | 全体贴表情概率 (0.0~1.0) |
| `global_emoji_id` | `46` | 全局贴表情的 emoji_id |
| `ai_debug_log` | `false` | 是否启用 AI 调试日志 |
| `NICKNAME` | `[]` | 机器人昵称（建议留空） |

### 主动冒泡（chat_ai）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `bubble_enabled` | `true` | 是否启用主动冒泡 |
| `bubble_idle_minutes` | `30` | 群冷清判定时长（分钟） |
| `bubble_cooldown_minutes` | `180` | 冒泡冷却时长（分钟） |
| `bubble_chance` | `0.5` | 冒泡概率 (0.0~1.0) |
| `bubble_ai_enabled` | `true` | 是否用 AI 生成冒泡内容 |

### RAGFlow 知识库（chat_ai）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `ragflow_enabled` | `false` | 是否启用知识库检索增强 |
| `ragflow_base_url` | `http://127.0.0.1` | RAGFlow 服务地址 |
| `ragflow_api_key` | - | RAGFlow API 密钥 |
| `ragflow_kb_ids` | `[]` | 知识库 ID 列表 |
| `ragflow_top_k` | `5` | 检索返回条数 |
| `kb_summary_enabled` | `true` | 是否自动生成聊天总结 |
| `kb_summary_max_chars` | `4000` | 总结最大字符数 |
| `kb_summary_model` | - | 总结使用的模型（留空用默认） |

### Redis 配置

排行榜、今日老婆、修仙插件均依赖 Redis（不可用时修仙插件降级为内存缓存）。各插件使用相同的前缀配置项：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `redis_host` | `localhost` | Redis 服务器地址 |
| `redis_port` | `6379` | Redis 端口 |
| `redis_db` | `0` | Redis 数据库编号 |
| `redis_password` | `""` | Redis 密码 |

## 注意事项

- `.env` 文件包含敏感信息，已被 `.gitignore` 忽略
- `NICKNAME` 配置建议设置为空列表 `[]`，避免概率回复失效
- 首次使用需要通过管理员命令添加群/用户白名单
- 人格切换功能支持「雌小鬼」（默认）和「邻家大姐姐」两种人格
- 表情功能需要机器人具有设置消息表情的权限
- 排行榜功能需要 Redis 服务支持，数据保留 2 天
- 知识库功能需要配置 RAGFlow 服务，相关命令仅私聊可用
- 微博功能仅支持私聊使用，需要用户在白名单中
- 欢迎语功能需要机器人具有群成员加入通知权限
- 修仙插件数据按群隔离存储于 SQLite，Redis 不可用时自动降级为内存缓存（重启后丢失）
