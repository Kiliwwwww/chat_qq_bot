# QQ Chat Bot

基于 [NoneBot2](https://nonebot.dev/) 的多功能 QQ 机器人，支持 AI 对话、群聊管理、知识库检索、微博动态、今日老婆以及修仙挂机游戏等功能。

## 插件概览

| 插件 | 说明 |
|------|------|
| `chat_ai` | AI 对话、白名单管理、人格切换、广告撤回、知识库、主动冒泡 |
| `ranking` | 基于 Redis 的每日群消息排行榜 |
| `weibo` | 查看微博用户最新动态与图片 |
| `daily_wife` | 今日老婆 / 原神家庭（头像合成图片） |
| `tarot` | 今日运势（塔罗 / 小六壬，基于 QQ+日期的确定性占卜） |
| `lottery` | 补给箱开箱抽奖（网页高保真 GIF、每日三次、结果查询） |
| `meme_sync` | 奶-hub 表情包每日自动同步 + 群内 AI 陪伴表情包（增量下载、已存在跳过） |
| `xiuxian` | QQ 群修仙挂机游戏 |

此外，项目内置一个基于 **Qwen3-TTS** 的本地语音合成服务 `qwen-tts`（独立 Docker 服务），提供语音朗读与 AI 自主语音回复能力，详见 [语音功能](#语音功能qwen3-tts)。

## 功能特性

- **AI 对话**：接入 OpenAI 兼容 API，支持上下文记忆与多 AI 服务切换
- **图片识别**：支持发送图片给 AI 分析（视觉 API）
- **知识库检索**：接入 RAGFlow，AI 自主决定是否检索群知识库
- **聊天记录总结**：定时/手动将群聊记录与总结同步至知识库
- **群聊概率回复**：可配置回复概率与冷却，避免刷屏
- **主动冒泡**：群聊冷清时主动发言暖场（AI 生成 + 预设语兜底）
- **私聊/群聊白名单**：仅允许指定用户私聊、仅在指定群启用
- **人格切换**：默认「雌小鬼」与「邻家大姐姐」两种人格
- **广告检测与撤回**：关键词 + AI 双重判定，自动撤回广告消息
- **复读检测**：自动跟随群友复读消息，支持随机复读
- **表情贴纸**：给指定用户/全体群友消息自动贴表情
- **欢迎语系统**：新成员入群自动发送欢迎语
- **管理员系统**：通过命令管理白名单、提示词、AI 服务等
- **排行榜**：基于 Redis 的每日群消息排行榜
- **微博动态**：查看微博用户最新动态和图片
- **今日老婆 / 原神家庭**：每日抽取 CP 并合成头像图片
- **今日运势**：以 QQ 号+日期为种子确定性占卜，支持塔罗牌（现状/挑战/指引）与小六壬（六宫排盘）
- **补给箱开箱**：使用网页高保真截图生成 GIF，每个 QQ 号每天最多抽三次，并保存今日物品与价值
- **表情包自动同步**：每天定时拉取 [奶-hub](https://nai-hub.com/) 最新表情包，增量下载并自动跳过已有文件
- **群内陪伴表情包**：在指定群开启后，AI 回复自动带上一张随机表情包，另有概率单独甩图活跃气氛
- **修仙游戏**：完整的挂机修仙玩法（灵修 + 蛊修）
- **语音朗读**：本地 Qwen3-TTS 合成语音，支持 `/朗读`、定向群发语音；AI 可自主决定用语音回怼

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
python -m playwright install --with-deps chromium
```

### 2. 配置环境

复制并编辑 `.env` 文件：

```bash
cp .env.example .env
```

主要配置项：

```env
# AI 配置
ai_api_key=你的API密钥
ai_base_url=https://api.example.com/v1
ai_model=mimo-v2.5

# 管理员QQ号（只有此人可修改白名单等设置）
admin_qq=123456789

# 群消息回复概率 (0.0~1.0)
group_reply_chance=0.05
```

### 3. 运行机器人

```bash
python bot.py
```

### 4. 访问文档

启动后访问 http://localhost:8080/website/ 查看 API 文档。

OneBot 反向 WebSocket 连接地址：`ws://localhost:8080/onebot/v11/ws`。

> 使用 Docker 部署请参考 [DEPLOY.md](./DEPLOY.md)。

| 命令 | 说明 |
|------|------|
| `/今日运势` / `/塔罗` / `/tarot` | 默认以塔罗牌占卜今日运势（抽取现状/挑战/指引三张牌） |

- 塔罗：从 78 张完整牌组抽取三张，位置为现状牌 / 挑战牌 / 指引牌；会告知 AI 今天的阳历日期。
- 小六壬：以真实农历月/日为基、按「月上起日，日上起时」推演，落宫为大安 / 留连 / 速喜 / 赤口 / 小吉 / 空亡之一；会告知 AI 今天的农历日期（依赖 `lunardate`）。

### 表情包同步（meme_sync）

| 命令 | 别名 | 说明 |
|------|------|------|
| `/同步表情包` | `/表情包同步` | 立即同步一次奶-hub 表情包（仅管理员） |
| `/开启奶龙` | - | 在当前群开启奶龙表情包功能（仅管理员，群聊） |
| `/关闭奶龙` | - | 在当前群关闭奶龙表情包功能（仅管理员，群聊） |
| `/奶龙状态` | - | 查看当前群开关状态与表情库数量（仅管理员，群聊） |

每天 0 点（可配置）自动从 [奶-hub](https://nai-hub.com/) 拉取最新表情包，已下载过的文件直接跳过，只补新增内容，因此不会重复占空间。图片按「角色 / 分类」存放到 `data/naihub-img/`，并生成 `_index.json` 记录每张图的标题、分类、标签与来源。下载优先直连 GitHub，连不上时自动切换到镜像加速入口。

开启功能的群里，机器人会这样使用表情包：

- **回复后跟图**：AI 回复完之后，单独再发一条图片消息；图片不引用、不 @ 任何人，是独立的一条消息（类似「文字一条 + 图片一条」）
- **概率控制**：默认每次回复都会跟一张（`meme_attach_chance=1.0`）。`meme_attach_chance` 与 `meme_standalone_chance` 描述的是同一件事，代码取两者较大值，因此不会出现同一次回复连发两张的情况；想让跟图变成偶发，把两个值都调小即可
- **冒泡跟图**：主动冒泡暖场之后也会单独跟一条图片消息（可用 `meme_bubble_attach=false` 关掉）

群开关既可以在 `.env` 的 `meme_group_ids` 里预先指定，也可以由管理员在群里用 `/开启奶龙`、`/关闭奶龙` 动态调整；动态调整的结果不会与 `.env` 冲突，且 `/关闭奶龙` 的优先级更高。

## 语音功能（Qwen3-TTS）

机器人通过一个独立的本地语音合成服务 `qwen-tts`（基于 [Qwen3-TTS](https://github.com/QwenLM/Qwen3-TTS)，FastAPI + GPU）实现文字转语音，qqbot 通过 HTTP 调用，二者完全解耦。

### 架构

```
qqbot ──HTTP POST /tts──▶ qwen-tts (FastAPI, GPU)
      ◀──── audio/mpeg ───┘
```

### 启动

`docker-compose.yml` 已内置 `qwen-tts` 服务（`gpus: all`），需要宿主机具备 NVIDIA GPU 及容器 GPU 直通能力：

```bash
docker-compose up -d qwen-tts
docker-compose logs -f qwen-tts   # 首次启动会下载模型（约 5GB，缓存在 ./qwen-tts/cache）
```

服务就绪后访问 `http://127.0.0.1:8000/health`，返回 `{"status":"ok", ...}` 即正常。

### 命令

| 命令 | 别名 | 说明 |
|------|------|------|
| `/朗读 <内容>` | `/read` | 用当前音色朗读内容并发送语音 |
| `/发语音 <群号> <内容> [语气指令]` | `/sendvoice` | 向指定群发送语音（管理员；内容含空格时用 `\|` 分隔语气） |
| `/音色 <描述>` | `/语气` | 设置全局语气/口音（如「用台湾腔说话」），`/音色 默认` 恢复（管理员） |

### AI 自主语音回复

AI 通过 function calling 获得 `send_voice` 工具，可自主决定是否用语音回复（例如被攻击、辱骂、挑衅或情绪激烈时），此时**只发语音、不发文字**。语气（`instruct`）由 AI 根据对话上下文自行决定（如「嘲讽」「生气地」），若未给出则回退到默认语气。该能力受 `tts_enabled` 控制，关闭后仅文字回复。

### 服务接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/health` | 健康检查（`loaded` 表示模型是否已加载到显存） |
| GET | `/speakers` | 列出可用音色 |
| POST | `/tts` | `{text, speaker?, language?, instruct?, temperature?, top_p?, top_k?, seed?}` → `audio/mpeg` |

### 服务端环境变量（`docker-compose.yml` 中 qwen-tts 服务）

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `TTS_MODEL` | `Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice` | 模型（可换 `0.6B` 版本省显存） |
| `TTS_TOKENIZER` | `Qwen/Qwen3-TTS-Tokenizer-12Hz` | 语音编解码器 |
| `TTS_SPEAKER` | `Vivian` | 服务端默认音色 |
| `TTS_LANGUAGE` | `Chinese` | 默认语言 |
| `TTS_DEVICE` | `cuda:0` | 推理设备 |
| `TTS_VOLUME_FILTER` | `loudnorm=I=-16:TP=-1.5:LRA=11` | ffmpeg 响度处理（调大音量） |
| `TTS_TEMPERATURE` | `0.6` | 采样温度（越低越稳定） |
| `TTS_TOP_P` | `0.85` | Top P 采样 |
| `TTS_TOP_K` | `30` | Top K 采样 |
| `TTS_SEED` | `42` | 随机种子（固定后同文本输出一致，留空则随机） |

| `meme_sync_out_dir` | `data/naihub-img` | 图片保存目录 |
| `meme_group_ids` | `[]` | 开启奶龙表情包功能的群号，例如 `[123456789]` |
| `meme_attach_chance` | `1.0` | 回复后单独跟一条表情包的概率（1.0 表示每条回复都跟一张） |
| `meme_standalone_chance` | `0.2` | 同义概率，与上一项取较大值生效 |
| `meme_bubble_attach` | `true` | 主动冒泡之后是否也单独跟一条表情包 |
| `meme_max_bytes` | `8388608` | 单张表情包体积上限，超过的图片不进候选池 |

以上配置都有默认值，不写也能正常工作；需要改时间或筛选时才加到 `.env`。

表情包以 **base64 内嵌**方式发送，不依赖 QQ 框架与机器人容器共享文件系统（机器人在容器里、QQ 框架在容器外时，传本地路径对方读不到，会导致整条消息发送失败）。发送失败时会自动退回纯文本重发，不会因此丢掉 AI 回复。

## 注意事项

- `.env` 文件包含敏感信息，已被 `.gitignore` 忽略
- `NICKNAME` 配置建议设置为空列表 `[]`，避免概率回复失效
- 首次使用需要通过管理员命令添加群/用户白名单
- 人格切换功能支持「雌小鬼」（默认）和「邻家大姐姐」两种人格
- 表情功能需要机器人具有设置消息表情的权限
- 排行榜功能需要 Redis 服务支持，数据保留 2 天
- 知识库功能需要配置 RAGFlow 服务，相关命令仅私聊可用
- 微博功能仅支持私聊使用，需要用户在白名单中
- 欢迎语功能需要机器人具有群成员加入通知权限
- 修仙插件数据按群隔离存储于 SQLite，Redis 不可用时自动降级为内存缓存（重启后丢失）
- 表情包同步默认每天 0 点自动执行，下载的是第三方仓库的公开表情图，请遵守原仓库的许可与使用范围
- 语音功能依赖本地 `qwen-tts` 服务（需 NVIDIA GPU 及容器 GPU 直通），首次启动下载约 5GB 模型到 `./qwen-tts/cache`；设置 `tts_enabled=false` 可禁用全部语音能力
